# DAMarHGCL

**Density-Adaptive Margin and Hierarchical Sampling for Heterogeneous Graph Contrastive Learning**

Official implementation of the paper "Density-Adaptive Margin and Hierarchical Sampling for Heterogeneous Graph Contrastive Learning".

## Requirements

```bash
pip install -r requirements.txt
```

## Datasets

Supported datasets:

- ACM
- DBLP
- IMDB
- YELP

## Quick Start

```bash
# Run on ACM dataset with default parameters
python main.py --dataset ACM

# Run on other datasets
python main.py --dataset DBLP
python main.py --dataset IMDB
python main.py --dataset YELP
```
